\section{Additional Details}
\label{app:details}

\para{Prompts.} The user messages, wrapped in each model's chat template, are:
\begin{itemize}[leftmargin=*,itemsep=0pt,topsep=0pt]
    \item \emph{Factual:} ``Answer the following trivia question. Reply with only the answer (a few words), no explanation. Question: \{q\} Answer:''
    \item \emph{Reasoning:} ``Solve the following math word problem. Think step by step, then write the final answer on the last line in the form `The answer is N'. \{q\}''
    \item \emph{Code:} ``Complete the following Python function. Return the complete function (signature and body, plus any imports it needs) in a single python code block. \{prompt\}''
    \item \emph{Creative:} ``Write a short, original story of about 150 words that begins with the sentence below. Make it vivid, surprising and engaging. Output only the story. First sentence: \{s\}''
\end{itemize}

The judge is \url{Qwen3-8B-AWQ}. We served all models with \vllm~0.32.

\para{Deviations from the plan.} We had planned to use a 14B judge, but it did not fit on the shared GPUs, so we used Qwen3-8B-AWQ instead. Because of GPU contention, we adapted the memory budget for each model. Per-request seeds keep outputs independent of these choices. We added the matched-$n$ seed-variance check after seeing the difference in benchmark sizes.
